# Five-company Pilot Plan

## Gate 1 - Technical
- authentication works
- tenant boundaries verified
- import validation works
- deterministic Profit Audit runs
- approval workflow works
- audit events recorded

## Gate 2 - Privacy and security
- production vendors documented
- DPAs/subprocessors recorded
- EU region decisions documented
- file retention/deletion tested
- backups and restore documented
- AI terms approved
- REAL_CUSTOMER_DATA_READY explicitly approved

## Gate 3 - Controlled onboarding
Only the five approved pilot organizations receive production access.
Each organization gets its own tenant and memberships.
No cross-tenant operational account may be used for customer-facing access.

## Pilot success measures
- successful import rate
- validation error rate
- time to first Profit Audit
- approved Opportunities
- documented Results
- attributed customer value
- support incidents
